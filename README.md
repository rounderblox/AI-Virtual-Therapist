# AI-Virtual-Therapist
🌸 AI-Powered Virtual Therapist — A Streamlit based app that combines NLP (GPT-3.5) and facial emotion recognition (DeepFace) to deliver empathetic mental health support. Includes risk detection, private journaling, and guided breathing exercises , all processed securely in-session.

Features & Functions:
1. Therapeutic Chat

Interactive chat using Streamlit.
Users share feelings; AI replies empathetically via LLM.
Chat history is stored within the session.

2.  Facial Emotion Detection

Uses DeepFace and webcam to detect user emotions in real time.
Adds emotional context to AI responses for more empathy.

3.  Risk Detection & Alerts

Scans messages for distress or self-harm indicators.
Sends immediate warning and alert email if risk detected.

4. Live Webcam View

Displays real-time webcam feed using OpenCV.
Enhances interaction and supports emotion analysis.

5.  Private Journaling

Lets users write and save personal reflections.
Includes daily guided prompts for self-awareness.

6.  Breathing Exercise

Guided relaxation tool with adjustable duration and cycles.
Promotes mindfulness and stress relief.

7.  Custom UI Design

Calming blue-themed interface with styled text and buttons.
Enhances readability and user comfort.

8.  Session Management

Maintains chat and journal data using Streamlit session state.
Ensures smooth, persistent user experience.

9.  LLM-Powered Responses

Uses GPT-based model for context-aware, empathetic dialogue.
Combines user input + emotion detection for natural replies.
